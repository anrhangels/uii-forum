# Текущее состояние — 05.11.2026

Проект `/home/anrhangels/uii-forum`, локальный адрес http://127.0.0.1:8088/ . phpBB 3.3.19; production-контейнер PHP 8.3; MariaDB 10.11. Данные сохранены в Docker volume. Отдельный PHP 8.5 CLI внутри `runtime/` используется только для разработки; production на него не зависит.

## Реализовано и применено

Расширение `uii/portal` 0.5.0, миграции v001-v011. Тема UII Modern, реальная панель сотрудника, мобильное меню, светлый/тёмный режим. Локаль `ru` по умолчанию, авторский частичный перевод с английским fallback. VigLink и CDN отключены. Публичная регистрация, подписи, дни рождения, публичная статистика и RSS отключены либо исключены из пользовательского интерфейса.

Четыре группы ролей, назначение первоначального руководства основателю phpBB, управление сотрудниками с серверными ограничениями. Случайные временные пароли хешируются штатным сервисом phpBB, TXT формируется только в HTTP-ответе, обязательная смена при входе. Блокировка и сброс отзывают сеансы и ключи автологина.

Жалобы и протоколы, запросы с серверными 48 часами, проверки, форумная тема для каждого нового дела, карточки с этапами и доказательствами, назначение ответственного, закрытие и архив, журнал, поиск и фильтры. Задачи вычисляются из состояния дел, не создают дубликатов. Конфликт версий редактирования отклоняется. Для закрытия без ответа требуется просрочка, руководство и основание — текущая политика приложения, не официальный RP-регламент.

Сервер проверяет доступ к карточке и связанной теме, в том числе по post_id. Гостевые документы недоступны. В штатной выдаче вложений добавлена проверка связи с делом; реальное загруженное вложение пока не проверено интеграционно. В собственных формах загрузок нет: используются HTTP(S)-ссылки, сервер их не скачивает. Вложения phpBB ограничены 256 КБ/файл, 3 файла/сообщение, общая квота 20 МБ. Аватары до 256 КБ.

## Оставшиеся ограничения

- Полной русификации стандартного phpBB нет. Собственные рабочие экраны — русские, в ACP, справке и редких ошибках остаются английские строки. Перечень fallback-строк по исходным файлам — `localization-gaps.json`. Официальный пакет остаётся недоступным из текущей сети.
- Предварительный протокол опроса нужно согласовать по оригиналу, которого среди материалов нет. Точные RP-правила не выдумывались и не объявлены официальными.
- Прямые реальные вложения, массовая нагрузка, все страницы стандартной ACP/UCP и восстановление дампа на отдельной БД не тестировались. Это не основание заявлять о полной готовности к production.
- Перенос на Beget не выполнялся; HTTPS и доступные версии PHP на конкретном аккаунте нужно проверить. У Free есть ограничения, способные временно нарушить работу сессий; см. beget.md.
- Тестовые аккаунты `Qatest_*` и дела `QA:` оставлены с явной маркировкой. Приветственная тема phpBB сохранена, скрыта из основного интерфейса; пользовательский контент не удалялся.

Сайт не публиковался, удалённый репозиторий не создавался. SQL-дампы, конфигурация и старые кэши сохранены в `snapshots/` вне публичного корня.
