# Очистка 0.7.0 - 06.11.2026

Локальная папка проекта: примерно 817 МиБ до очистки и 411 МиБ после неё (включая инструменты, историю и артефакты). Приложение app занимает около 37 МиБ. Архив кода - около 4.8 МиБ.

Удалено:

- `runtime/browsers/chromium-1248` - обычный браузер; все существующие проверки запускают Chromium в headless-режиме без channel/executablePath и используют `chromium_headless_shell-1248`. Соответствующая ветка выбора проверена в установленном Playwright. Запуск с headless:false теперь потребует повторной установки обычного Chromium.
- `runtime/usr/include`, `phpize`, `php-config`, `onig-config` - инструменты сборки расширений. Существующий локальный PHP CLI и mysqli работают без них; PHP-проверки повторно прошли.
- Контактные шаблоны/события и contacts.css - пустой блок удалён по запросу владельца. В ACP simple-header событие заменено загрузкой оформления технического окна.
- Старые отдельные workspace/cases/team/admin.svg - заменены общими символами в visuals.html.
- navbar_footer.html и tweaks.css собственной темы - повторная нижняя навигация и слой IE9 больше не подключаются.
- Дублирующий визуальный футер и блок регистрации в собственных шаблонах, неиспользуемые ссылки RSS и cookie-баннера, старые CSS-селекторы уже удалённых собственных компонентов.
- SVG-заглушки мужского/женского аватара - заменены WebP-портретами. Исходные PNG остаются в пользовательской папке «Загрузки».

Сохранено:

- Весь исходный phpBB, prosilver, vendor и языковой fallback. Отключённый экран не доказывает, что его PHP-классы не нужны установщику миграций, ACP, общим сервисам или будущим обновлениям. Удаление зависимостей по названию ломает эти связи и почти не влияет на вес относительно инструментов разработки. Целостность сверена с официальным архивом.
- Лицензии и сведения об авторах в исходных файлах. Изменено отображение пользовательской темы.
- База, фото, загруженные вложения, SQL/конфигурационные снимки и резервные копии.
- Headless browser, Playwright, PHP CLI, доменные/интеграционные тесты и официальный ZIP для проверки целостности.

`python3 scripts/package-release.py` создаёт закрытый архив кода в runtime. В нём отсутствуют конфигурация с паролями, пользовательские файлы, кэш, локальные инструменты, собственные тесты и документация ядра кроме LICENSE/CREDITS. Защитные .htaccess и index.htm каталогов сохраняются. Архив не является резервной копией и не содержит данных для восстановления действующего сайта. Для переноса нужны также config.php, SQL и files.
