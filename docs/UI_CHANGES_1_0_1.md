# Изменения интерфейса 1.0.1 — 07.11.2026

По трём скриншотам пользователя:

- Полностью убран блок логотипа в боковой панели, включая подпись. Графический знак и favicon также убраны из собственных шаблонов ACP и установщика. Файлы эмблемы сохранены для совместимости старых копий, но интерфейс их не подключает.
- Из рабочего экрана «Управление» убраны четыре группы дублирующих технических ссылок и поясняющий блок. Остались сотрудники, настройки УИИ, журнал, редактор левого меню и одна кнопка входа в панель форума. Штатные технические настройки phpBB не отключались и не удалялись. Неиспользуемое построение списка ссылок убрано из контроллера.
- Тёмная тема приведена к примеру Discord: фон #000000, поверхности #0b0b0d, нейтральные серые границы #29292e. Синие фоновые оттенки заменены нейтральными; акцентные ссылки сохранены. Палитра согласована в портале, ACP и установщике. Светлая тема не изменялась.

Новых миграций и изменений серверной конфигурации нет. Ресурсы версионированы 1.0.1, кэш шаблонов сохранён и пересобран. Для отображения достаточно Ctrl+F5, пересборка Docker не нужна.

Проверки: синтаксис PHP и 26 шаблонов, пути SVG/ресурсов, базовый контраст текста (минимум 7.62:1 в тёмной теме), браузерный проход светлой/тёмной тем и размеров 360/768/1440 px. Журнал — runtime/test-results/ui-1.0.1.log. Резервная копия до изменений — snapshots/before-black-theme-20261107-135430.tar.gz.
