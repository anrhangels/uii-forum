# Новая установка УИИ 1.0.0

Эта инструкция предназначена для **новой пустой установки**. Для переноса действующих аккаунтов, дел и фотографий используйте [spaceweb.md](spaceweb.md). Не устанавливайте новую копию поверх работающего сайта.

## Требования

PHP 8.1+ (Docker проекта использует 8.3), MySQL/MariaDB с InnoDB, расширения mysqli, mbstring, JSON и стандартные возможности phpBB. Для полной проверки изображений нужен GD; Docker также содержит intl и zip. HTTPS обязателен для публичного рабочего сайта. Должна быть возможность запускать PHP CLI либо обратиться к поддержке хостинга для завершающей настройки. Нужен доступ на запись в cache, files, store и images/avatars/upload. Режимы доступа зависят от пользователя PHP; не выдавайте всему сайту 777.

## Подготовка пакета

Из каталога исходного проекта:

```bash
python3 scripts/package-install.py
```

Команда создаёт `release/uii-install-ДАТА/`: website.zip, CLI-настройщик, эту инструкцию и контрольные суммы. Проверяется SHA-256 исходного phpBB. В архив не попадают действующий config.php, база, загруженные фотографии, кэш, резервные копии и тестовые пароли. Собственные шаблоны установщика накладываются только на пакет новой установки; рабочее ядро phpBB не изменяется.

## Установка

1. Создайте отдельную пустую базу и пользователя с доступом к ней. Запишите адрес сервера, порт, имя базы, пользователя и пароль. Не используйте реквизиты локального Docker на хостинге.
2. Распакуйте website.zip в корень нового сайта. До завершения установки ограничьте внешний доступ средствами хостинга.
3. Откройте `https://ваш-домен/install/app.php`. По умолчанию выбран русский язык. Установщик оформлен в стиле УИИ, поддерживает светлую и тёмную темы.
4. Пройдите проверку требований. Введите уникальный логин основателя, надёжный пароль длиной до 30 символов (ограничение первоначального установщика phpBB) и реальный адрес для технического восстановления. Не используйте примерные или тестовые пароли.
5. Заполните реквизиты БД. В Docker сервер — `db`, порт 3306; на хостинге используйте параметры провайдера. Префикс оставляйте уникальным. Завершите штатную установку phpBB.
6. Создайте приватную папку вне public_html. Поместите `finish-fresh-install.php` из пакета туда, не в веб-корень.
7. Выполните с тем же PHP, которым обслуживается сайт:

```bash
php /home/account/private/finish-fresh-install.php /home/account/public_html /home/account/private
```

Настройщик включает расширение УИИ и его миграции, устанавливает UII Modern, русский язык и МСК, закрывает публичную регистрацию, отключает почту и CDN, переносит install в приватную папку. При ошибке после начала настройки форум остаётся закрытым; устраните причину и повторите команду. Проверьте доступ PHP к config.php после ограничения прав.

8. Войдите основателем. Откройте «Управление», создайте сотрудника, передайте ему временные реквизиты защищённым способом. Проверьте создание дела и обсуждение. Не публикуйте TXT с паролями.
9. В системной панели проверьте домен, HTTPS/cookie_secure и путь cookies. Проверьте отсутствие прямого доступа к files/uii_evidence. Для nginx правила .htaccess не действуют: храните фото за веб-корнем через UII_EVIDENCE_PATH или настройте запрет на сервере.
10. Сохраните первую резервную копию БД, config.php и файлов, затем снимите внешнее ограничение доступа.

Если PHP CLI на тарифе отсутствует, настройку выполняет поддержка хостинга либо администратор на совместимом сервере перед переносом. Не загружайте CLI-настройщик в public_html ради запуска через браузер.

## Тёмная тема и ошибки установки

Кнопка темы находится в шапке установщика. Выбор хранится в браузере. Ошибка подключения к БД: проверьте адрес и порт, права пользователя, существование базы и разрешение подключения с сервера PHP. Незаписываемый каталог: настройте владельца и минимально необходимые права. Не отключайте проверки безопасности ради прохождения установки.

## Проверки перед открытием

Вход/выход, смена пароля, создание сотрудника и дела; работа всех трёх типов дел; права обычного сотрудника; закрытие и архив; запрет повторного сохранения старой версии; фото и запрет прямой ссылки; обе темы на телефоне; установка удалена из публичного корня. Сборщик и отображение установщика проверяются автоматически; успешную установку на конкретном хостинге нужно подтвердить отдельно.
