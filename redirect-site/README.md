# Переходник УИИ для GitHub Pages

Независимая статическая страница в стиле UII. Через 2 секунды перенаправляет посетителя на **http://mevdokimov.temp.swtest.ru/**. Кнопка позволяет перейти сразу. При отключённом JavaScript используется HTML meta refresh, ручная ссылка остаётся доступной.

Никакой проверки безопасности/браузера, аналитики, сторонних шрифтов, библиотек, пользовательских данных или серверного кода нет. Полоса показывает только задержку перехода. Светлая и глубокая тёмная темы выбираются по системным настройкам; уменьшение анимации учитывается.

## Публикация

1. В репозитории `anrhangels/uii-forum` откройте **Settings → Pages**.
2. В **Build and deployment → Source** выберите **GitHub Actions**.
3. В **Actions → Переходник УИИ · GitHub Pages** запустите **Run workflow → main**. В дальнейшем изменения папки `redirect-site/` автоматически публикуются при push в main.
4. После успешного deployment адрес: **https://anrhangels.github.io/uii-forum/**. Если GitHub Pages использует иной адрес/подключённый домен, действующий URL показан в Settings → Pages и в результате workflow.

Workflow загружает только публичные файлы этой папки (index.html и .nojekyll). Файлы форума, база, vendor, credentials и production-комплекты не публикуются на Pages. PHP на GitHub Pages не выполняется; сам форум остаётся на хостинге.

HTTPS GitHub Pages защищает страницу-переходник. После перехода форум открывается по **HTTP**: переходник не добавляет ему HTTPS и не скрывает конечный адрес. Авторизация и пользовательские данные обрабатываются только самим форумом.

## Изменение адреса

В `index.html` одновременно поменяйте URL в JavaScript, в ссылке кнопки и в noscript meta refresh, а также отображаемое имя хоста и этот README. Не считывайте адрес перехода из параметров URL: направление должно оставаться фиксированным.
